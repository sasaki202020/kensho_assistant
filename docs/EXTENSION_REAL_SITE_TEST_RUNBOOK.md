# Chrome拡張機能 実サイト非送信確認手順

この手順はローカルfixture合格後のPhase A・1サイト確認用である。架空プロフィールだけを使い、最終送信は行わない。本人プロフィールを使うPhase Bとは同じ試行にしない。

## 事前条件

1. ブランチとcommit SHAを記録する。
2. 全テスト、Webスモーク、P1 preflightが成功していることを確認する。
3. `submitted_count_auto=0`を確認する。
4. スクリーンショットとPlaywright traceを無効にする。
5. 対象サイトの締切、応募条件、重複応募禁止を本人が確認する。

フォーム対応の事前確認:

- 初回フォームは、信頼度にかかわらず欄ごとの割り当てを人間が承認する。
- 「保護者名」「ハンドル名」「賞品」「応募理由」「感想」などは入力しない。
- 確認済みテンプレートがあっても、origin、pathname、fingerprint、送信ガード、
  PIIセッションが一致しなければ入力せず`FORM_CHANGED_REVIEW_REQUIRED`で停止する。

## 実行

1. 独立版拡張機能だけが有効であることを確認し、拡張機能IDをローカル運用記録へ残す。
2. 対象ページを本人がChromeで開く。
3. 初回だけ拡張機能アイコンを押し、ページ内パネルを表示する。
4. 「このサイトで常に有効にする」を押し、表示中originだけを許可する。
5. 自動再読み込み後、Chromeツールバー操作なしでパネルが表示されることを確認する。
6. CAPTCHA、ログイン、外部iframe、危険項目がないことを確認する。
7. マスク済みプレビュー、判定根拠、フォームfingerprintを確認する。
8. 初回は欄ごとの割り当てを承認し、入力対象外は「入力しない」にする。
9. 「入力を実行」を1回だけ押す。
10. 各項目、対象外欄、同意欄、賞品欄を本人が画面で確認する。
11. `POST_FILL_VERIFICATION_PASSED`以外なら送信せず、ロールバック結果を確認する。
12. Enter、送信ボタン、確認ボタンが自動操作されていないことを確認する。
13. 「入力を元に戻す」を押し、全変更が戻ったことを確認する。
14. 「セッション情報を消去」で架空PIIを削除する。
15. 候補状態と通常履歴の前後差分が0であることを確認する。
16. 検証終了後に自動起動も解除する場合は「このサイトで自動起動しない」を押す。

## 即時停止

- CAPTCHA、ログイン、認証、外部iframeを検出した。
- prototype改変または自動送信試行を検出した。
- 誤入力、値リセット、候補不一致がある。
- Service Worker epochが変化した。
- PIIがログ、HTML、storage、画像、traceへ残った疑いがある。

停止時も最終送信を押さず、次のサイトへ自動移動しない。
