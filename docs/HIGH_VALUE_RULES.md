# 高額判定と応募優先度

## 判定

既定のしきい値は最大個別賞品額30,000円です。`総額`、`合計`、`総計` だけの金額は個人賞品額に使いません。

価格不明でも、車・バイク、現金・金券、旅行、PC・スマートフォン、大型家電、高級時計、ブランド品などは高額候補として残し、`NEEDS_REVIEW` と表示します。価格を推測しません。

## 優先度

画面上の名称は「応募優先度スコア」です。当選確率や期待値は算出・表示しません。賞品価値、当選人数、応募手間、価格信頼度、URL・条件確認、締切を0〜100点へ集約し、内訳を表示します。

## 自動入力に関する規約

フォーム診断時にページ本文をメモリ内で正規化し、自動応募・ツール・bot等（`automated_entry`）と代理応募・本人以外の入力等（`proxy_entry`）の記載を調べます。同一文（句点・改行区切り）または前後40文字以内に禁止・無効等があれば、自動入力の準備を `terms_prohibit_automation` で除外します。診断の `terms_policy` には `restricted`、`categories`、`uncertain`、`checked_at` だけを追加し、規約本文は保存しません。キューCSVには既存列の末尾に4列を追加します。キーワードだけ、または本文取得失敗は確認が必要な状態として残し、ブロックしません。本人による条件・規約確認と手動応募、手動送信済み記録は継続できます。これは文字列による補助判定であり、別ページ・画像内の規約や未知の言い換えは見逃し、同一文内の無関係な禁止表現は誤検知する場合があります。未診断の旧レコードは自動的に規約確認済みにはしません。
