# 独立版Chrome拡張の導入

対象フォルダー:

```text
C:\Users\goo10\Projects\kensho_assistant\extension
```

## 導入手順

1. Chromeで`chrome://extensions/`を開く。
2. 旧パスから読み込んだ「懸賞入力補助」が有効なら、削除せず一度無効にする。
3. デベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」で上記フォルダーを選ぶ。
4. 表示された拡張機能IDを、ローカル運用記録へ記録する。IDは個人情報ではないがGitには保存しない。
5. 新旧両方が同時に有効でないことを確認する。
6. 使用するサイトごとに「このサイトで常に有効にする」を本人が押し、origin権限を再許可する。

旧拡張機能は自動削除しません。二重に有効化された場合、ページ内パネルは入力・解析を無効化し、一時プロフィールとcapabilityを消去します。送信ガードは解除しません。

## 確認項目

- 新しい拡張機能IDをChromeの詳細画面で確認した。
- 旧拡張機能は無効である。
- 新しい拡張機能だけが有効である。
- 必要なoriginだけを再許可した。
- 再読み込み後もパネルは1個、送信ガードは1個である。
- `data-kensho-duplicate-extension`が設定されていない。

二重起動警告が出た場合は入力を続けず、`chrome://extensions/`で片方を無効にしてページを再読み込みします。
