# 売る前チェック App Store 公開ガイド

## 1. App Store 用メタデータ（ドラフト）

### アプリ名
- 売る前チェック

### サブタイトル（30文字以内）
- 買取トラブルを防ぐ、売る前のひと呼吸

### 説明文（ドラフト）

```
「売る前チェック」は、不用品や貴金属を売る前の不安を減らすためのチェックアプリです。

■ できること
・チラシチェック: ポストに入っていた買取チラシの文言から、注意した方がよい表現をお知らせ
・商品チェック: 売ろうとしている品物が、トラブル相談の多い品目かどうかを確認
・見積もりチェック: 「一式」「キャンセル不可」など、あいまい・要注意な表現を確認
・判定は「問題なさそう / 確認推奨 / 即決注意 / 相談推奨」の4段階
・そのまま使える断り文例（コピー対応）
・公開されている相場情報へのリンク集
・消費者ホットライン188のご案内

■ 安心して使えます
・入力した内容は端末の中だけで判定され、外部に送信されません
・会員登録は不要です
・履歴の保存はオプションで、いつでも全件削除できます

■ ご注意
本アプリの判定はキーワードに基づく参考情報です。査定額・真贋・法律判断を保証するものではなく、特定の事業者についての評価を行うものでもありません。困ったときは消費者ホットライン188にご相談ください。
```

### キーワード（100文字以内）
- 買取,訪問買取,押し買い,チラシ,見積もり,貴金属,着物,相場,クーリングオフ,188,消費者,トラブル

### カテゴリ
- プライマリ: ユーティリティ / セカンダリ: ライフスタイル

### 年齢制限
- 4+（不適切コンテンツなし）

- トラッキング: なし

## 3. App Store Connect 登録手順

1. Apple Developer Program に登録（年額 約12,980円 / 99 USD。個人 or 法人）
2. [App Store Connect](https://appstoreconnect.apple.com) > マイApp > 「+」> 新規App
3. プラットフォーム: iOS / 名前: 売る前チェック / プライマリ言語: 日本語
4. バンドルID: Xcodeで設定したものを選択（事前に developer.apple.com > Identifiers で作成）
5. SKU: 任意の管理用文字列（例: `sellbeforecheck001`）
6. 「App情報」: カテゴリ・プライバシーポリシーURL（公開URL必須）を設定
7. 「価格および配信状況」: 価格を設定（無料 or 有料。有料なら有料App契約と銀行口座・税務情報の登録が必要）
8. 「Appのプライバシー」: データ収集なしで申告
9. ビルドをアップロード（Xcode > Archive > Distribute）し、バージョン情報・スクリーンショット・説明文を入力
10. 審査に提出

## 4. TestFlight 配布手順

1. Xcode で Archive → App Store Connect にアップロード
2. App Store Connect > TestFlight タブでビルドが処理されるのを待つ（10〜30分）
3. 内部テスト: App Store Connect ユーザー（最大100人）を追加 → 即配布可、審査不要
4. 外部テスト: グループを作り公開リンクを発行（最大10,000人）→ 簡易審査（Beta App Review）あり
5. テスターは iPhone に TestFlight アプリを入れ、招待メール/リンクから参加

## 5. 審査で問題になりやすい点と対策（本アプリでの対応状況）

| リスク | ガイドライン | 対応 |
|---|---|---|
| 「Webサイトをラップしただけ」と判定される | 4.2 Minimum Functionality | オフライン完結・履歴保存・コピー機能・電話発信(tel:188)などアプリとしての実用機能を実装済み。審査メモに「全機能オフライン動作・外部サーバー不使用」と明記する |
| 法律・医療等の専門助言とみなされる | 5.1 / 1.4 | 全画面に「参考情報であり法律判断を保証しない」免責を表示済み。説明文でも明記 |
| 特定事業者への誹謗と受け取られる表現 | 1.1 | 「悪徳」「詐欺業者」等の断定表現を判定文言から排除（自動テストで担保） |
| 「AI」表記への根拠確認 | 2.3.1 誇大表現 | アプリ名・説明文では「AI査定」をうたわない。「キーワードに基づくチェック」と正直に記載 |
| プライバシーポリシーURL未設置 | 5.1.1 | 公開URLが必須。`PRIVACY_POLICY.md` を GitHub Pages 等で公開すること |
| 電話番号(188)の取り扱い | - | 公的窓口の案内であり問題なし。「公的相談窓口の案内」であることを説明文に記載済み |

### 表現の修正方針（実装済み）
- ×「この業者は危険です」→ ○「急いで決めさせる表現が含まれています」
- ×「査定額は◯円です」→ ○「公開相場へのリンクで自分で確認」
- ×「クーリングオフできます」→ ○「一般に8日間できるとされています。詳しくは188で確認を」
