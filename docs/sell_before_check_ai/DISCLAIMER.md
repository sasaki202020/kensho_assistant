# 「売る前チェック」免責事項

最終更新日: 2026年6月11日

## 本アプリの性質

「売る前チェック」の判定は、あらかじめ登録されたキーワードに基づく**参考情報**です。
判定は「問題なさそう」「確認推奨」「即決注意」「相談推奨」の4段階で表示されます。

## 保証しないこと

本アプリは以下を行わず、また保証しません。

1. **査定額の算定・保証** — 正確な買取額・査定額を算出するものではありません。
2. **真贋判定** — 品物が本物かどうかの判定は行いません。
3. **法律判断** — クーリング・オフの可否など、個別ケースの法的判断は行いません。アプリ内の法制度に関する記載は一般的な情報であり、個別の事案については消費者ホットライン188・消費生活センター・弁護士等にご確認ください。
4. **特定事業者の評価** — 特定の事業者が悪質・違法であるとの判断・認定は行いません。判定はあくまで入力された文章中の表現に対する一般的な注意喚起です。

## 責任の制限

本アプリの利用、または利用できなかったことにより生じたいかなる損害（取引上の損失を含む）についても、開発者は責任を負いません。売却・契約の最終判断は、利用者ご自身の責任で行ってください。
