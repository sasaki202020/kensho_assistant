# 高額懸賞機能 仕様

この機能の目的は、明示的な賞品価値または高額カテゴリの候補を選別し、既存の応募準備経路へ渡すことです。

高額懸賞の流れは次のとおりです。

`候補取り込み -> 高額判定 -> 応募優先度表示 -> 公式ページ確認 -> 既存拡張で入力補助 -> 人間確認 -> 最終送信前停止`

完全自動応募、最終送信、CAPTCHA処理、ログイン、規約同意は対象外です。

## 成功条件

- 3万円以上の明示された最大個別賞品額を抽出できる
- 総額と個人が受け取る最大賞品額を混同しない
- 金額不明の高額カテゴリは `NEEDS_REVIEW` とする
- 優先度の内訳を表示する
- 既存の候補キュー、Chrome拡張、送信ガードを再利用する
- `submitted_count_auto=0` を維持する
