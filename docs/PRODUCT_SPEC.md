# 商品仕様書

## 商品コンセプト

「懸賞生活」を入口に、懸賞情報を整理し、応募条件を分類し、危険案件を避けながら、ユーザー本人がローカルPC上で1件ずつ応募を管理できる補助ツール。`v0.2-beta-final` では自動スキャンと人間確認モードを追加し、候補の収集・分類・診断を分離する。

完全自動応募botではなく、送信前確認と承認を前提にした応募支援ツールとする。

## v0.2-beta-final の安全モード

- `READY_FOR_FILL`: 自動入力補助してよい安全度の高いフォーム
- `REVIEW_ONLY`: 年齢、地域、同意、入力不足など人間確認が必要なフォーム
- `REVIEW_ONLY` では診断、入力候補表示、スキップ理由表示、応募ページ表示のみを行い、送信はしない
- `REVIEW_ONLY` では年齢、規約同意、メルマガ、任意項目を自動入力しない
- `v0.2-beta-final` では本番送信を推奨せず、本番応募してよいかは必ず人間が確認する
- 自動スキャンでは個人情報を使わない

## 対象ユーザー

- 懸賞に日常的に応募する個人
- 応募履歴を残したい人
- 締切や条件の見落としを減らしたい人
- SNS懸賞よりWebフォーム応募を中心に使いたい人
- 個人情報をクラウドに預けたくない人

## 解決する課題

- 懸賞情報が散らばっていて管理しにくい
- 応募条件や締切の確認に手間がかかる
- 危険な応募や規約違反を避けにくい
- 応募済みの重複管理が難しい
- 個人情報の扱いが不安

## 対象にする応募

- カンタン応募
- Webフォーム応募
- アンケート応募
- クイズ応募
- 無料サンプル応募
- 企業公式フォーム応募

## 対象外にする応募

- X懸賞
- Instagram懸賞
- LINE懸賞
- Facebook懸賞
- アプリ応募
- 会員登録が必要なもの
- ログインが必要なもの
- 購入・レシート・バーコードが必要なもの
- 酒・たばこなど年齢確認が強いもの
- CAPTCHAがあるもの
- 規約に自動応募禁止があるもの
- 応募条件が不明確なもの

## 禁止事項

- CAPTCHA突破
- ログイン回避
- 年齢確認の自動突破
- SNSの自動フォロー
- SNSの自動いいね
- SNSの自動リポスト
- X / Instagram / LINE の自動応募
- 複数アカウント応募
- 1人1回制限の回避
- 同一キャンペーンへの重複応募
- 応募規約に反する応募
- 懸賞生活の掲載情報や画像の再配信
- 懸賞生活の公式サービスであるかのような表現
- 高速巡回やサイトに負荷をかける処理

## 個人情報の扱い

- 個人情報はローカルPC内の `config/profile.enc` に暗号化保存する
- `profile.json` は Git 管理に含めない
- `profile.enc` は `.env` の `KENSHO_PROFILE_KEY` で暗号化する
- ログに個人情報を残さない
- スクリーンショットは既定OFFにする
- 保存前に注意表示を出し、ユーザー責任で扱う

## 免責事項

- これは応募補助ツールであり、当選を保証しない
- 各キャンペーン規約の確認責任はユーザーにある
- 規約違反用途には使わない
- 懸賞生活の公式ツールではない
- 開発者は応募結果や当選結果を保証しない
- サイト仕様変更や停止に対する動作保証はない

## 販売時の注意

- 懸賞生活の公式ツールと誤認されない表現にする
- 「当選率アップ」などの断定的表現は使わない
- 個人情報をサーバーで預かる設計にしない
- SNS自動操作や規約回避を前面に出さない
- 法務・特商法・プライバシー表記を別途整える

## MVP範囲

- ローカル個人情報管理
- `REVIEW_ONLY` の手動確認支援
