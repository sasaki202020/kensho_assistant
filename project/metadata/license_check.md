# License Check

## 使ってよいもの

- 自作の画像
- 自作の音源
- 明確に再配布可と確認できた素材

## 使わないもの

- YouTube動画から取得した音源
- 権利不明のBGM
- 権利不明の効果音
- 規約で再配布が禁止された素材

## 作業前チェック

- 素材の出典を記録した
- 再配布条件を確認した
- 商用利用可否を確認した
- クレジット表記の要否を確認した
- AI生成素材はAI生成と分かる状態で扱う

## 配布前チェック

- `assets/audio/` に権利不明ファイルが残っていない
- `assets/images/` に権利不明ファイルが残っていない
- `assets/overlays/` に権利不明ファイルが残っていない
- `exports/` に完成版MP4だけを置く
- 自動アップロードの仕組みは入れない
